# Structure Lab — แบบฝึกหัด Data Structures

เว็บฝึกทบทวนเนื้อหา DSA จากสไลด์ Lec 01–11

## วิธีเปิด

เปิด index.html ในเว็บเบราว์เซอร์ได้โดยตรง ไม่ต้องติดตั้ง package หรือเชื่อมต่อบริการภายนอก

## วิธีใช้

- แต่ละหมวดมี 40 ข้อ เลือกหมวดเพื่อฝึก 15 ข้อต่อรอบ พร้อมตรวจคำตอบและอ่านเหตุผลทันที
- ระบบจำข้อที่เคยสุ่มฝึกและพักไว้จนกว่าข้ออื่นในหมวดจะถูกใช้ก่อน จากนั้นจึงเริ่มวนรอบใหม่
- เลือกข้อสอบจำลองเพื่อทำ 50 ข้อ โดยสุ่ม 5 ข้อจากแต่ละหมวด และพักข้อสอบเก่าจนกว่าจะใช้คลังหมวดนั้นครบ
- ข้อสอบจำลองจะแสดงเฉลยหลังส่งคำตอบ
- คำถามทุกประเภทมีตัวเลือก A–D ทั้งวิเคราะห์แนวคิด/ข้อความ ทำนายผลโค้ด และเลือกส่วนเติมโค้ด
- คะแนนสอบล่าสุดและคิวกันข้อซ้ำเก็บใน local storage ของเบราว์เซอร์เครื่องนี้

## ไฟล์หลัก

- index.html — หน้าเว็บ
- styles.css — รูปแบบและ responsive layout
- app.js — การฝึก ข้อสอบ และการตรวจคำตอบ
- data.js และ extra-data.js — คลังโจทย์และเฉลย 400 ข้อ
